펫타운 에셋 확인

합성 — 세 장이 한 세트로 보이는가 (논리 360×640 을 ×2 로)

성장 3단계 — 아기 80 / 어린이 104 / 어른 128 (전부 ×2)

표정 4종 (어른 ×2) — 기본 / 눈 감음 / 시무룩 / 입 벌림

펫 — ×1 / ×2 / ×4

아이템 — ×2 / ×4 / ×8

무엇을 볼 것인가

  • 펫의 실루엣이 배경에서 즉시 분리되는가. 외곽선이 끊긴 곳은 없는가.
  • 눈·입이 형태로 읽히는가. 뭉개져 얼룩으로 보이면 최종 크기가 작은 것이다.
  • 세 장의 외곽선 두께와 색 온도가 같은가. 하나만 튀면 그 에셋만 다시 뽑는다.
  • 벽·바닥에 흩뿌려진 점이 없는가. 있으면 --despeckle 을 켠다.
  • 어두운 배경으로 바꿔도 밝은 에셋의 가장자리가 사라지지 않는가.
  • 세 단계가 크기만 다른 같은 펫으로 보이는가. 외곽선 두께가 셋 다 같은가.
  • 처진 눈썹이 바깥쪽이 아래인가. 안쪽이 내려가면 화난 얼굴이다.
  • 입 벌림이 입 자리에 있는가. 옆구리에 검은 덩어리가 생겼으면 팔 주름을 잡은 것이다.
